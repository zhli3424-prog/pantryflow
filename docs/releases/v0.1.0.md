# PantryFlow v0.1.0 — First Public Release

The first public MVP connects pantry tracking, practical recipe recommendations, cooking completion, and history in one mobile-first workflow.

## Included

- Pantry inventory measured as estimated meals
- Expiry-aware recommendations with expired-item exclusion
- Controlled household recipe candidates with optional LLM ranking
- Pydantic Structured Output validation and backend inventory checks
- Persistent recommendation batches and single-dish replacement
- Transactional, idempotent inventory deduction after cooking
- Cooking history
- Key-free Mock provider and optional OpenAI-compatible provider
- Automated backend tests, frontend build checks, and GitHub Actions CI

## Notes

- The public demo uses the Mock provider; it does not claim live-model output.
- SQLite is suitable for this single-instance disposable demo, not a multi-user production deployment.
- Expiry dates are prioritization hints and do not replace food-safety judgment.
